# 词影迷踪局域网双端版

原版 `index.html` 保留不动。本目录是局域网版，由一台电脑当队长端、另一台电脑当队员端，服务端负责同步整局游戏状态。

## 启动

```bash
cd D:\idea\caici
python lan/server.py
```

默认监听 `0.0.0.0:8000`。启动后终端会打印本机地址和局域网地址：

- 本机打开 `http://127.0.0.1:8000/`
- 另一台电脑打开 `http://<这台电脑的局域网IP>:8000/`

两台电脑都打开首页后，队长电脑选择“队长端”，队员电脑选择“队员端”。如果某个角色已经被连接，新连接会提示角色已被占用。

## 依赖

局域网版需要 Python 3.11 以上和 `aiohttp`：

```bash
python -m pip install aiohttp
```

## 验证

可以用无头 Chrome 打开两个页面分别选择队长端和队员端，验证队长端可见全部颜色、队员端隐藏颜色，并确认翻词和回合切换会同步到两端。
