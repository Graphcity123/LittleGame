# 词影迷踪多人局域网版

原版 `index.html` 和双端局域网版 `lan/` 均保留。本目录是新增的五人局域网版，支持：

- 红方队长
- 蓝方队长
- 红方队员
- 蓝方队员
- 观察者

## 启动

```bash
cd D:\idea\caici
python multi/server.py
```

默认监听 `0.0.0.0:8010`。启动后终端会打印本机地址和局域网地址：

- 本机打开 `http://127.0.0.1:8010/`
- 其他电脑打开 `http://<这台电脑的局域网IP>:8010/`

首页选择对应角色。红方队长、蓝方队长各占一个连接；红方队员、蓝方队员和观察者都可以有多位。只有红蓝队长、至少各一位红蓝队员和至少一位观察者都连接后，观察者才能开启新局。开始后无需保持全员在线，离线角色在需要行动时重新连接即可继续。

## 视角

- 红方队长：查看全部颜色，只在红方回合提交提示。
- 蓝方队长：查看全部颜色，只在蓝方回合提交提示。
- 红方队员：隐藏颜色，只在红方回合翻词，可有多位。
- 蓝方队员：隐藏颜色，只在蓝方回合翻词，可有多位。
- 观察者：使用隐藏颜色的队员视角，只负责开启新局；可查看红蓝双方提示弹窗。所有弹窗不显示确认/关闭按钮，强制显示 3 秒后自动关闭。

双方计分、当前回合、双方提示和历史词语对所有角色可见。

## 对局配置（观察者）

观察者在开启新局之前（大厅阶段），以及上一局结束后、开启下一局之前，可以调整对局配置：

- 行数 / 列数：4–8（默认 5 行 5 列，可配成非方形如 5×6）
- 红队目标词数量（默认 9）
- 蓝队目标词数量（默认 8）
- 炸弹词数量（默认 1）

无效词数量 = 行数 × 列数 − 红队 − 蓝队 − 炸弹。下一局默认沿用上一局的配置；首次开局默认 5 行 5 列、红 9 / 蓝 8 / 炸弹 1。对局进行中配置不可更改。
