# 阿瓦隆 · 5–10 人局域网联机版

基于 `role.md` 实现的隐藏身份推理游戏，支持 **5–10 人动态人数**，走局域网联机，服务端权威同步，各玩家身份信息按角色过滤展示。

## 启动

```bash
pip install -r requirements.txt
python server.py            # 默认监听 0.0.0.0:8020
```

启动后终端会打印本机与局域网访问地址。5–10 名玩家用浏览器打开同一地址：

- 本机：`http://127.0.0.1:8020/`
- 其他电脑：`http://<服务器局域网IP>:8020/`

进入大厅后先设定游戏人数（5–10），满员后任意一人点击「开始游戏」。

## 游戏流程

1. 每人填写昵称加入；满员后任意一人点击「开始游戏」。
2. 系统随机分配座位与身份，所有人确认身份。
3. 系统发放阵营信息（梅林看坏人、派西维尔看梅林+莫甘娜、红方队友互认），所有人确认信息。
4. 进行五轮游戏，每轮上车人数按人数配置（5 人 `2/3/2/3/3`、6 人 `2/3/4/3/4`、7 人 `2/3/4/4/4`、8–10 人 `3/4/4/5/5`），每轮依次为：
   - **选人 → 发言**：车长选人，随后全体顺时针发言表达看法。
   - **发车投票**：全员匿名投票，赞成**过半数**发车成功。失败则顺时针下一位车长再选人；连续两次失败后第三次取消投票、强制上车。
   - **任务**：车上成员匿名投票，好人必须投成功；至少一票失败则本轮失败。
5. 任务失败三次 → 坏人胜利；任务成功三次 → 强制刺客行刺。此外刺客在游戏进行中可随时主动行刺；刺中梅林则坏人胜利，否则好人胜利，行刺后本局立即结束。

## 角色

角色随人数动态配置（详见 `role.md` 的「不同人数游戏配置」表）：

| 角色 | 阵营 | 出现人数 | 特点 |
| --- | --- | --- | --- |
| 梅林 | 好人 | 全部 | 知道谁是好人谁是坏人（不知道坏人具体身份；把莫德雷德认成好人） |
| 派西维尔 | 好人 | 全部 | 知道梅林和莫甘娜是谁，但分不清谁是谁 |
| 忠臣 | 好人 | 若干 | 普通平民，无特殊能力 |
| 莫甘娜 | 坏人 | 全部 | 与除奥伯伦以外的红方互认；知道刺客 |
| 刺客 | 坏人 | 全部 | 与除奥伯伦以外的红方互认；可随时主动行刺，刺中梅林则坏人胜利 |
| 爪牙 | 坏人 | 7–8 人 | 与除奥伯伦以外的红方互认 |
| 奥伯伦 | 坏人 | 9–10 人 | 不被红队友看见，但能被梅林看见 |
| 莫德雷德 | 坏人 | 9–10 人 | 梅林会把他认成好人 |

### 深水局（任意 5–10 人勾选即开）

大厅勾选「深水局」后整个网页进入深色模式，并启用两个特殊角色：

| 角色 | 特点 |
| --- | --- |
| 兰斯洛特 | 随机替代一名忠臣；初始好人，**第 3 轮 50% 随机叛变为坏人**（私密通知本人与梅林）；叛变后破坏任务会当场公开 |
| 湖中仙女 | 第 1 轮队长的下一位担任；第 2/3/4 轮任务后各查验一人，查验后令牌转交给被查验者 |

房规（不分深水局）：任务成功/失败**不显示具体票数**——结果弹窗、轮次轨道、悬浮气泡、轮次详情、事件记录都只写「成功/失败」，对局结束复盘才揭示谁投了什么；发车投票的赞成/反对票数仍公开。

## 设计说明（对 role.md 的取舍）

- 刺客可**随时主动行刺**：游戏进行中（选人 / 投票 / 任务阶段）即可点「发起刺杀」进入行刺；任务成功三次后仍会强制进入行刺环节。两种情况都会立即结算本局。
- **红方互认**：莫甘娜、刺客、爪牙、莫德雷德彼此互认，但都看不到奥伯伦；兰斯洛特（即使叛变）不参与互认（见 `server.py` 的 `role_info`）。
- 好人投任务失败会被服务端拒绝（`好人阵营必须投任务成功`），从根本上防止误投。
- 投票全程匿名，不公布谁投了什么：发车投票只公布赞成/反对票数；任务投票连票数也不公布（见上方房规）。
- 刺客**主动**发起行刺（游戏中途）需要二次确认；强制行刺阶段选择目标也需要二次确认。
- 刷新页面会沿用同一个玩家 id 并**自动重新加入**（`sessionStorage` 记住昵称），可回到原身份继续；大厅阶段断开会自动释放座位。

## 前端规范

- 顶部导航栏**正中间**醒目展示「第 x 轮 · xx 阶段（选人 / 发言 / 发车投票 / 任务投票 / 湖中仙女 / 刺杀）」。
- 顶部常显：**任务轮次**（按人数配置，成功蓝 / 失败红 / 当前轮高亮）与**编号对应人物**（1–n 号座位，选人 / 刺杀目标在此点击选择）。
- 主框为**任务执行页**（当前操作区）；**自己的身份**与**事件记录**为侧边小框；信息确认的阵营信息合并为单个框。
- 每次发车投票结束后弹出**醒目提示**（成功蓝 / 失败红 + 赞成 / 反对票数）；任务投票结束只提示成功 / 失败（不显示票数）；**行刺开始时**也有醒目提示（深色金色）。任务成功三次触发的**强制行刺**会先后弹出「任务成功」与「行刺开始」两条提示；中途主动行刺则直接覆盖为行刺提示。
- 发车 / 任务投票进行中显示「已投票 x/y · 未投票：…」名单，方便看清谁还没投（只显示进度，不透露投了什么）。
- 对局结束显示「全员身份复盘」；可点「复盘」退回棋盘，**点击轮次框**查看该轮发车与任务的具体投票情况（含多次发车尝试）。
- hover 已完成任务的轮次框，弹出该轮信息，成功用蓝色、失败用红色：

```
第x轮：成功/失败
---------
车长：编号·id
投票人：
编号1·id1
编号2·id2
...
```
